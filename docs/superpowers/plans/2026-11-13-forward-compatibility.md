# Поддержка следующих версий Codex

Цель: обновлять Codex без ручного выпуска дополнения для каждого нового номера.
Выбор реализации сделан агентом в рамках запроса пользователя.

## Решение

Встроенные профили остаются закреплёнными по SHA-256. Для неизвестной последней
стабильной версии скачивается официальный пакет по HTTPS с проверкой каждого
перенаправления. Его структура должна точно соответствовать одному из двух
известных адаптеров. После распознавания фиксируются SHA-256 исходного пакета,
исходного и изменённого JS; дальнейшая подготовка использует обычные проверки.
Только успешный изолированный GUI-тест разрешает сохранить локальный профиль
и предложить установку. Локальные профили привязаны к отпечатку дополнения.
Предыдущая проверенная резервная копия сохраняется. Несовместимая структура,
ошибка теста, отмена или изменение файлов оставляют рабочую установку как есть.

Рассмотрены: список заранее выпущенных профилей (не решает запрос), слепое
применение патча (не подтверждает совместимость), локальное распознавание с
GUI-проверкой (выбрано). Это поддержка совместимых будущих структур; изменение
внутреннего протокола OpenAI может потребовать обновления самого дополнения.

## План выполнения

- [ ] Регрессии: неизвестная версия проходит полный updater и сохраняется только
  после успешного теста; плохой отчёт, подмена и несовместимый JS отклоняются.
- [ ] `scripts/update_package.py`, `renderer_adapter.py`, `native_adapter.py`:
  `discover_latest(target, output, expected_version)` скачивает только последнюю
  официальную версию, `discover_profile(vsix, version, target)` распознаёт пакет;
  явный профиль используется исключительно в изолированной подготовке.
- [ ] `update-core.js`: discovery callback, сохранение/загрузка проверенных
  локальных профилей, сохранение прежней recovery, запрет подмены встроенного
  профиля. Хеш кандидата проверяется до и после GUI и перед установкой.
- [ ] `update-ui.js`, `extension.js`, `test/update-probe.js`: реальная последняя
  версия, локальные профили при старте и таймаутах, профиль кандидата только в
  ExtensionMode.Test; предложение обновления по лёгкой периодической проверке.
- [ ] Полный npm test; реальный отдельный VS Code с официальным пакетом,
  отсутствующим в списке профилей тестового helper; повторная проверка файлов.
- [ ] Версия 0.7.0, README/CHANGELOG/аудит, установка, проверка на диске,
  коммит и push с проверкой удалённого SHA.

## Особое внимание

Неподдерживаемая архитектура; неподтверждённый/чужой локальный профиль;
подмена пакета между проверкой и установкой; авария и старый recovery;
восстановление профиля после перезапуска. Секреты и рабочая история не входят
в GUI-тест. Скачивание и тестовое окно запускаются по команде пользователя,
фоновая проверка получает только метаданные и не прерывает диалоги.
