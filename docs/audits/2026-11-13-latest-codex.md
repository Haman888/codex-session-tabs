# Поддержка актуального Codex — 13.11.2026

В Codex Session Tabs 0.6.5 добавлен профиль для официального Codex
**26.1111.21308, darwin-x64**. На момент проверки это последняя стабильная
Intel-сборка: результат `scripts/update_package.py --latest --platform darwin-x64`
из API Microsoft Marketplace — `26.1111.21308`. Apple silicon этим изменением
не проверяется; его прежний профиль сохранён.

## Изменение адаптера

В новой сборке общий загрузчик HTML заменил `getWebviewContent()`, а обработчик
сообщений принимает также `request-app-server-state`. Добавлен явный тип
структуры `shared-content-v1`; неизвестные структуры отклоняются. Патч
сохраняет штатные аргументы загрузчика, метаданные страницы и новые сообщения.
Подмена кода разрешается только после совпадения SHA-256 исходного файла;
результат также проверяется по закреплённому SHA-256.

Сохраняются независимые URI вкладок, последовательное создание новых вкладок,
отложенная инициализация скрытых панелей и watchdog 90 секунд для Intel.
Webview-ресурсы новой версии не патчатся. Настройки авторизации, CSP и пути
доступа к локальным ресурсам используются из официальной сборки.

  **8/8** проверок интерфейса, двух новых вкладок, языка, названий и индикаторов;

## Границы результата

Это поддержка конкретной актуальной сборки, а не обещание совместимости с
неизвестными будущими версиями. Новые версии требуют отдельного профиля и
проверки. Полная перезагрузка рабочего окна и реальные ответы модели не
входят в изолированные тесты. После локальной установки необходим
`Developer: Reload Window`, чтобы рабочее окно загрузило новые файлы.
