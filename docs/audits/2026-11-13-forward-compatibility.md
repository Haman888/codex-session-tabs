# Автоматическое распознавание новых сборок — 13.11.2026

Версия дополнения: 0.7.0. Команда обновления теперь выбирает последнюю
стабильную версию из Microsoft Marketplace. Если её нет во встроенном списке,
скачивается официальный пакет, проверяются издатель, версия, архитектура,
редактор диалогов и однозначное совпадение известной структуры JS.

После распознавания фиксируются SHA-256 VSIX, исходного и изменённого JS.
Пакет проходит обычную подготовку, проверку дерева файлов и изолированный
GUI-тест. Лишь полный успешный отчёт позволяет сохранить локальный профиль
и предложить установку. Проверенная резервная версия сохраняется отдельно.
Локальный профиль связан с отпечатками дополнения и самого профиля; изменение
одного из них делает старый отчёт непригодным.

Фоновая проверка получает только метаданные: через пять минут после старта,
когда нет работающих ответов, затем не чаще раза в сутки в данном окне.
Она предлагает команду обновления. Скачивание пакета, тестовое окно,
установка и перезагрузка сами по себе не запускаются.

## Проверка безопасности

- Встроенные профили продолжают требовать закреплённые SHA-256; локальная
  запись не может заменить встроенный профиль.
- Для неизвестной версии происхождение задаёт HTTPS-загрузка с официального
  URL OpenAI в Marketplace. Каждый redirect до запроса допускается только
  на разрешённый HTTPS-хост Microsoft, без credentials и посторонних портов.
  Затем фиксируется хеш полученного архива; это не независимая проверка
  криптографической подписи издателя.
- Тесты проверяют отказ небезопасных перенаправлений до перехода по ним.
  Архивные пути, symlink и дубликаты проверяются до распаковки.
- XML ограничен по размеру, декодируется строго как UTF-8; NUL, DOCTYPE и
  ENTITY запрещены до ElementTree. Регрессии покрывают внешние сущности,
  внутренние сущности и обход через UTF-16.
- Профиль кандидата из переменной окружения используется исключительно
  в реальном `ExtensionMode.Test`. Производственный запуск игнорирует его.
- Native bridge, авторизация и CSP официального Codex в этом изменении
  не переписывались; тестовый `CODEX_HOME` отдельный, без рабочей истории
  и токенов пользователя. Запросы к модели не являются частью GUI-теста.

## Границы поддержки

Распознаются два известных устройства редактора: `classic` и
`shared-content-v1`. Новые номера версий с совместимой структурой больше не
требуют выпуска дополнения. Изменение внутренних API или структуры OpenAI
может потребовать нового адаптера; тогда проверка отклоняет установку.
Нельзя проверить ещё не выпущенные версии или обещать их совместимость.
Реальные ответы модели и рабочее окно пользователя после Reload Window
не входят в изолированный тест.
