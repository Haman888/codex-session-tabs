# Codex Session Tabs

[English](README.md) · Русский

**Форк [kasiaalena/codex-session-tabs](https://github.com/kasiaalena/codex-session-tabs).** Добавляет поддержку Mac на Intel (официальный Codex 26.1007.21434), запускается без напоминания о настройке защиты и исправляет ряд ошибок; подробности — в [CHANGELOG](CHANGELOG.md). Идентификатор расширения прежний, `kasiaalena.codex-session-tabs`, поэтому форк заменяет исходную установку и сохраняет её состояние.

Отдельные вкладки Codex, панель открытых сессий, короткие названия и оранжевые индикаторы завершения для VS Code. Это неофициальное дополнение к расширению Codex от OpenAI. Проект не связан с OpenAI и не поддерживается OpenAI.

**Поддерживаемая среда:** локальный VS Code на macOS, Python **3.9+** и системный `/usr/bin/sqlite3`. Профили совместимости: Intel (`darwin-x64`) с официальным Codex **26.1007.21434** — проверен на Mac с Intel в этом форке; Apple silicon (`darwin-arm64`) с официальным Codex **26.1021.22027** — без изменений относительно оригинала, где он и проверялся. На Mac с Apple silicon этот форк не запускался. Проверено на VS Code **1.145.0**. В манифесте указан минимум 1.106, но более старые версии VS Code, Windows, Linux и удалённые хосты не проверены.

**Предварительный выпуск 0.4.5 (форк).** Установщики: `codex-session-tabs-0.4.5-darwin-arm64.vsix` для Apple silicon и `codex-session-tabs-0.4.5-darwin-x64.vsix` для Intel. Скачайте их со страницы [релизов](https://github.com/Haman888/codex-session-tabs/releases) этого форка или соберите из исходников. Идентификатор пакета: `kasiaalena.codex-session-tabs`. Для замены прежней локальной установки с другим идентификатором нужен отдельный перенос состояния. Эта сборка не переносит его автоматически. Прежнюю установку следует сохранить до подготовки и проверки переноса.

## Возможности

- **Открытые сессии** показывает только вкладки Codex текущего окна. Нажатие переключает на вкладку, действие закрытия закрывает её.
- **История** показывает сохранённые разговоры без открытой вкладки. Выбор открывает переписку и переносит разговор в список открытых. Кнопка с часами также открывает попап с поиском по истории.
- **Новая вкладка** создаёт отдельный черновик. Временные названия: `Новый диалог 1`, `Новый диалог 2` и т. д. После перезапуска или перезагрузки окна счётчик начинается заново и пропускает номера открытых вкладок, в том числе восстановленных в фоне.
- После первого сообщения используется название, сформированное Codex. Автоматические подписи ограничены пятью словами и 36 символами. Дополнение не обращается к модели для генерации названий.
- Переименование доступно через контекстное меню вкладки или сессии. Сохранённый разговор переименовывается штатным API Codex. Ручное название может содержать до 120 символов.
- Вращающийся кружок в панели открытых сессий показывает, что ответ ещё готовится. После фонового завершения он сменяется оранжевой точкой. Состояние работы определяется по живым событиям Codex и не восстанавливается с диска после перезапуска.
- После завершения фонового ответа оранжевая точка появляется на значке вкладки и в панели. Точка снимается примерно через секунду просмотра готовой и видимой вкладки в активном окне VS Code. Само восстановление вкладок не снимает непрочитанные отметки.

Закрытие вкладки не удаляет и не архивирует сохранённый разговор. У пустого черновика нет сохранённой переписки до первого сообщения.

## Язык

Нажмите кнопку с глобусом или выполните **Codex: Language / Язык** в палитре команд. Доступны **English**, **Русский** и **Как в VS Code**. По умолчанию используется язык VS Code; для остальных языков выбирается английский. Настройка `codexSessionTabs.language` принимает `auto`, `en` или `ru`.

Выбор сразу меняет команды, меню, разделы панели, уведомления, даты и автоматические подписи пустых черновиков. Названия разговоров и ручные подписи сохраняются. Язык самого VS Code и официального чата Codex не меняется. Подписи в редакторе настроек VS Code следуют языку самого редактора. Уже открытые уведомления сохраняют прежний язык.

## Установка и настройка защиты

1. Установите официальное расширение Codex (`openai.chatgpt`) и войдите в свой аккаунт.
2. Скачайте VSIX соответствующей версии со страницы релизов или соберите его по инструкции ниже. В VS Code выполните **Extensions: Install from VSIX…** и выберите файл.
3. Выполните **Codex: Проверить и обновить Codex** и подтвердите диалог с размером загрузки. Папку официального расширения дополнение найдёт автоматически.
4. Дождитесь проверки и отдельно подтвердите установку. Поддерживаемая версия может быть старше последней версии Marketplace; номер устанавливаемой версии указан в диалоге.
5. После завершения текущих ответов выполните **Developer: Reload Window**. Рабочее окно не перезагружается без вашего действия.

Настройка скачивает утверждённый официальный пакет размером около **400 МБ**, сверяет SHA-256, готовит адаптер и проверяет его в отдельном окне VS Code. Требуется дополнительное место для распаковки и проверки. Процедура нагружает процессор и диск; запускайте её, когда другую работу можно прервать. На время проверки может появиться второй значок VS Code в Dock. Тестовый профиль использует пустую историю и не отправляет сообщения модели. По завершении тестовое окно закрывается автоматически.

После успешной проверки резерв сохраняется **до подтверждения установки**. Отмена в финальном диалоге сохраняет этот пакет и оставляет установленный Codex без изменений. Позже его можно установить командой **Codex: Восстановить проверенную версию Codex**, не повторяя скачивание и проверку.

Установка из локального VSIX закрепляет эту версию официального Codex и отключает её обычное автообновление. Настройки остальных расширений сохраняются. Явное ручное Update или Update All способно заменить адаптер. Неизвестные выпуски Codex автоматически не утверждаются: новый профиль совместимости требует проверки.

Сверьте скачанный установщик с файлом `SHA256SUMS.txt` из того же релиза. В терминале из папки с обоими файлами выполните `shasum -a 256 -c SHA256SUMS.txt`.

## Восстановление

Значок щита показывает состояние адаптера. Проверки выполняются при запуске, изменении списка расширений и периодически во время работы. Команды восстановления доступны и при сбое официального интерфейса Codex.

**Codex: Восстановить проверенную версию Codex** проверяет резерв и отдельно запрашивает разрешение установки. После завершения ответов следует перезагрузить окно. При проверке нового кандидата уже существующий рабочий резерв сохраняется; неуспешная проверка не разрешает установку.

Резерв привязан к сборке дополнения. После её обновления может потребоваться новая проверка, даже если версия официального Codex прежняя. Целый пакет от старого дополнения не подтверждает работоспособность нового сочетания. Не меняйте контрольные суммы в квитанции, чтобы обойти проверку.

В этом форке напоминания о настройке нет: ничего не скачивается и тестовое окно не открывается, пока вы сами не запустите **Codex: Проверить и обновить Codex** и не подтвердите диалог. При ошибке используйте канал **Codex Session Tabs** в разделе Output. Не публикуйте необработанные отчёты: они могут содержать локальные пути и названия разговоров.

## История и данные

Список читает локальные метаданные из `~/.codex/state_*.sqlite` и `session_index.jsonl`; поддерживается `CODEX_HOME`. Для списка не требуется читать тексты переписок. Адаптер не передаёт дополнению запросы, ответы или учётные данные. Название сохранённого разговора записывается только при явном переименовании через API Codex.

Запросы истории используют общий короткий кэш. При сбое чтения остаётся последний успешный список, а автоматические повторы откладываются. **Codex: Обновить сессии** повторяет запрос сразу. Если системный SQLite не может открыть базу, используется Python SQLite только для чтения. Временно недоступная история отличается от пустой.

Адаптер изменяет проверенные файлы официального расширения и сохраняет оригиналы с контрольными суммами. Он использует внутренние интерфейсы Codex, поэтому совместимость с каждым будущим выпуском не гарантируется. Неподдерживаемые версии и изменённые оригиналы отклоняются.

Официальное расширение и графика OpenAI не входят в этот репозиторий или VSIX дополнения. Значки индикаторов создаются локально из значка установленного расширения. Исходный и исправленный официальные пакеты хранятся на компьютере пользователя.

## Сборка и проверки

Из корня репозитория, с Node.js 22+ и Python 3.9+:

```sh
npm test
npm run package
```

Сборка использует стандартную библиотеку Python и не скачивает зависимости. Установщик: `dist/codex-session-tabs-0.4.5-darwin-arm64.vsix` на Apple silicon или `dist/codex-session-tabs-0.4.5-darwin-x64.vsix` на Intel. Для другого процессора выполните `python3 scripts/package.py darwin-arm64` или `python3 scripts/package.py darwin-x64`.

`npm test` создаёт небольшие искусственные данные в системной временной папке. Он не использует настоящую историю Codex и не запускает GUI-окна. Проверка при настройке защиты использует отдельный пустой профиль.

Отдельный разработческий сценарий `test/integration.js` требует минимум три сохранённых разговора и отдельное тестовое окно с подготовленной копией официального расширения и адаптером. До запуска отдельного процесса Code создайте новый закрытый профиль:

```sh
export CODEX_TABS_TEST_USER_DATA="$(node -p "require('node:fs').mkdtempSync(require('node:path').join(require('node:os').tmpdir(), 'cst-integration-'))")"
```

Передайте эту папку как `--user-data-dir "$CODEX_TABS_TEST_USER_DATA"`, папку подготовленного кандидата как `--extensions-dir`, этот репозиторий как `--extensionDevelopmentPath`, а `test/integration.js` как `--extensionTestsPath`. Не открывайте рабочую папку проекта в тестовом окне. До записи отчётов и изменения редакторов сценарий сверяет Test mode и реальное хранилище профиля; обычный запуск и несовпадающий профиль отклоняются. Наличие трёх разговоров проверяется до закрытия редакторов тестового окна. Рабочий профиль для этого сценария не используйте.

Отчёты и необязательные снимки сохраняются в новую закрытую папку `codex-tabs-report-*` внутри временного профиля: права папки 0700, файлов 0600. Путь выводится после завершения сценария. Переменная `CODEX_TABS_TEST_REPORT` больше не перенаправляет запись. Визуальная проверка использует тот же защищённый способ записи, общего пути по умолчанию нет. Проверяются вкладки, история, подписи, ручное переименование и имитация завершения; сообщения модели не отправляются. Отчёты могут содержать реальные названия и пути: храните их приватно и не включайте в публикацию.

Большие копии расширений, распаковки VSIX и GUI-профили следует держать вне открытых рабочих папок, предпочтительно в системной временной папке. Отдельный профиль VS Code не изолирует нагрузку от наблюдателей за файлами, а `.gitignore` этих наблюдателей не отключает.

## Ручная проверка и полное удаление

Основные команды настройки и восстановления находят папку автоматически. Для ручной проверки установите терминальную команду VS Code `code` в PATH, затем выполните из папки исходников соответствующей версии дополнения:

```sh
CODEX_EXTENSION_DIR="$(code --locate-extension openai.chatgpt)"
python3 scripts/native_adapter.py --extension-dir "$CODEX_EXTENSION_DIR" --check
```

Команда возвращает реальную папку без предположения о суффиксе платформы. При нестандартной папке расширений или профиле передайте те же параметры, с которыми запускаете VS Code. Если официальное расширение не найдено, остановитесь. Адаптер выбирает профиль совместимости по проверенным файлам на диске; для пакета, собранного под другой процессор, добавьте `--platform darwin-arm64` или `--platform darwin-x64`.

Для полного удаления сначала восстановите исходные официальные файлы:

```sh
python3 scripts/native_adapter.py --extension-dir "$CODEX_EXTENSION_DIR" --restore
```

Затем удалите **Codex Session Tabs** из списка расширений VS Code и перезагрузите окно после завершения ответов. Скрипт сверяет оригиналы и изменённые файлы и не перезаписывает чужие изменения. Используйте инструмент адаптера от установленной версии дополнения: новая схема не перезаписывает прежнюю без её подтверждённого резерва.
